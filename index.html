TL;DR

Fixed-horizon value backups either accumulate bootstrapping bias or wash out decisive short-range signals. VAST replaces fixed-horizon backups with recursive, horizon-adaptive value composition: it learns a future-state- and horizon-conditioned auxiliary value function \(G(s,s^+,k)\) by direct data supervision, and a stitching policy that picks the reward-maximizing horizon \(k\) and sub-goal \(s_k\).

The ALL Behind VAST

The quintessence of RL lies in value. However, conventional temporal-difference (TD) learning suffers from value-estimation bias that accumulates over the horizon, while extended-horizon methods, such as \(n\)-step TD backups and Q-chunking, adopt a rigid, fixed-horizon recipe that is often not flexible enough to capture complex value structures in long-horizon, multi-stage tasks.

Human decision-making adapts credit assignment to the task horizon. For distant objectives, humans conceptualize coarse sub-goals with a rough horizon estimate (e.g., walk straight for about 100 m, then turn right); for immediate, critical decisions, they focus on proximal, actionable consequences (e.g., decelerate and move left to avoid an obstacle). Truly adaptive, practically deployable mixed-horizon offline RL remains largely underexplored.

Figure 2: 4×4 grid navigation.

Central to the identified problem of fixed-horizon value-learning is that, while it may yield more robust value estimates, it is poorly suited to extracting policies for real-time, stepwise execution. When the backup sequence length is mismatched, crucial single-step signals can be washed out by sequence-level averaging, leading to the loss of precisely the information needed for accurate immediate decisions. Toy example (Figure 2) requiring navigation from the bottom-left to the top-right. The data include sub-optimal paths only (green path and purple path); the environment is specified by dark red, light red, and skull blocks, indicating high-, low-, and punitive-reward. The depth of blue in blocks indicates the value estimates from fixed-step/chunked value backups, and the optimal stitching value.

Although deliberately simple, this toy example can be viewed as a local subproblem embedded within a much larger maze. It shows that while coupling value updates to a fixed horizon can better stabilize long-horizon learning scenarios, it simultaneously obscures critical short-range decisions, thereby trapping learning in poor local optima. Stability should not be bought at the cost of erasing decisive short-term signals, motivating adaptive horizon modeling that preserves both robustness and flexibility. Therefore:

Could we automatically select a backup endpoint with an adaptive horizon?

The selection should be efficient, effective, adaptive, and optimal.

Method

Modeling Cumulative Return for Adaptive Horizons

This calls for a more general operator that can evaluate the cumulative return between any pair of states under a dynamically chosen horizon, rather than value estimates tied to fixed transition segments in the buffer.

Definition (Horizon-Conditioned Cumulative Return, G-function)
$$G(s, s^+, k) := \mathbb{E}_{\tau \sim \pi}\Big[\sum_{t=0}^{k-1} \gamma^t r(s_t, a_t) \;\Big|\; s_0 = s,\; s_k = s^+ \Big], \qquad |G(s,s^+,k)| < \tfrac{R_{\max}}{1-\gamma}.$$
Conditioning on both the terminal state \(s^+\) and the exact horizon \(k\), \(G\) maps any \(k\)-step reachable state pair to its return, breaking the dependence of value targets on fixed local backup segments.
Theorem (Temporal Compositionality)
$$G(s, s_k, k) = \mathbb{E}_{i \sim \mathrm{Unif}\{1,\dots,k-1\},\; s_i \sim \pi}\Big[\,{\color{#4F86B5}G(s, s_i, i)} + {\color{#E8445F}\gamma^i\, G(s_i, s_k, k-i)}\,\Big].$$
A long-horizon return decomposes into shorter, composable return segments.
Learning G-function from offline data
$$\mathcal{L}_{\mathrm{MC}} = \mathbb{E}_{\tau\sim\mathcal{D},\,k\sim\mathrm{Unif}\{1,\dots,K\}} \Big[\Big(G(s, s_k, k) - \sum_{t=0}^{k-1}\gamma^{t} r(s_t, a_t)\Big)^2\Big]$$ $$\mathcal{L}_{\mathrm{comp}} = \mathbb{E}_{\tau\sim\mathcal{D},\,k\sim\mathrm{Unif}\{2,\dots,K\},\,i\sim\mathrm{Unif}\{1,\dots,k-1\}} \Big[\Big(G(s, s_k, k) - \big(G(s, s_i, i) + \gamma^{i} G(s_i, s_k, k-i)\big)\Big)^2\Big]$$
Monte-Carlo regression gives direct return supervision; the compositional term enforces multi-scale temporal consistency and generalization across horizons.

Horizon-Adaptive Offline Policy Learning

With the definition of G, the state value admits a horizon-mixed form

$$V^\pi(s) = \mathbb{E}_{k\sim\mathrm{Unif}\{1,\dots,K\},\,s_k\sim\Gamma^\pi(s,k)}\big[G(s,s_k,k)+\gamma^k V^\pi(s_k)\big],$$

which recovers the standard Bellman equation at \(k=1\). To inject G into the backup process, we naturally further introduce the stitching Bellman operator.

Stitching Bellman operator
$$(\mathcal{T}^\pi_{\text{stitching}} V)(s) = \max_{k \in \{1,\dots,K\},\; s_k \sim \Gamma^{\pi}(s, k)} \; G(s, s_k, k) + \gamma^k V(s_k)$$
A joint maximization over horizon \(k\) and target state \(s_k\), restricted to pairs reachable from \(s\) in exactly \(k\) steps. Repeatedly applying this operator on \(V\) will converge to a unique fixed point \(V^\star\). It can be proved to be a \(\gamma\)-contraction mapping.

The stitching Bellman operator offers a new way to bootstrap the value estimates based on the optimal horizon lengths and target states. Together, there needs to be a stitching policy that simultaneously selects the best horizon \(k\) for value stitching and the reward-maximizing sub-goal. We have the following objectives:

$$\mathcal{L}_V = \mathbb{E}_{s \sim \mathcal{D},\,(k, s_k) \sim \pi_\text{stitch}(\cdot\mid s)} \Big[ L_{2}^{\tau}\big(\underbrace{G(s,s_k,k)+\gamma^k V(s_k)}_{V^\pi_\text{target}} - V(s)\big) \Big], \quad L_2^\tau(u)=|\tau-\mathbb{I}(u<0)|\,u^2$$ $$\mathcal{L}_{\pi_\text{stitch}} = \mathbb{E}_{(s,k,s_k)\sim\mathcal{D}}\Big[ \exp\big(\beta\,(V^{\mathcal{D}}_\text{target} - V(s))\big)\,\log \pi_\text{stitch}(k,s_k\mid s) \Big]$$

Action extraction. A goal-conditioned flow policy \(\pi_\text{exec}(a\mid s,s^+)\) is trained by imitation on in-trajectory future states. At test time, \(\pi_\text{stitch}\) outputs a horizon–sub-goal pair \((k, s_k)\); \(\pi_\text{exec}\) is conditioned on the sub-goal \(s_k\), and actions are filtered by rejection sampling:

$$a^\star = \arg\max_{a \in \{a^{(1)}, \ldots, a^{(N_\text{rej})}\} \sim \pi_\text{exec}(\cdot \mid s, s_k)} Q(s,a),\qquad (k, s_k)\sim\pi_\text{stitch}(\cdot\mid s).$$
